# Airbnb Clone

A full-stack Airbnb-inspired web application where users can explore properties, create their own listings, and book stays.

## Live Demo

[Visit Website](https://airbnb-frontend-1300.onrender.com/)

## Features

- User signup and login
- Browse available properties
- Create, edit and delete property listings
- Upload property images
- Search properties by city, title and landmark
- View individual property details
- Book properties by selecting check-in and check-out dates
- Rate properties
- Manage user profile and personal listings
- Responsive design for different screen sizes

## Tech Stack

**Frontend:** React.js, React Router, Tailwind CSS, Context API, Axios

**Backend:** Node.js, Express.js

**Database:** MongoDB,

**Authentication:** JWT, Cookie Parser

**Image Upload:** Multer, Cloudinary

**Deployment:** Render
